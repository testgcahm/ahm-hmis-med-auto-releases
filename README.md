## ⚡ 1-Click Update (Recommended)

1. Download [`update.bat`](https://raw.githubusercontent.com/testgcahm/ahm-hmis-med-auto-releases/main/update.bat).
2. Double-click to run **`update.bat`**.
3. It automatically:
   - Scans installed extensions across **Chrome, Edge, Brave, Vivaldi, and Opera**.
   - Downloads the latest verified release package.
   - Refreshes the files in your installation folder.
   - Signals the extension to reload in memory instantly.

## 🛠️ First-Time Manual Installation

1. Download [`extension.zip`](https://raw.githubusercontent.com/testgcahm/ahm-hmis-med-auto-releases/main/extension.zip) (or [`beta.zip`](https://raw.githubusercontent.com/testgcahm/ahm-hmis-med-auto-releases/main/beta.zip)).
2. Extract the archive into a permanent folder (e.g. `C:\Users\<user>\Documents\HMIS-Extension`).
3. Open your browser to `chrome://extensions`.
4. Enable **Developer mode** toggle in the top right corner.
5. Click **Load unpacked** and select your extracted folder.
